## About me

DevOps and Cloud Engineer based in Coimbatore, India. I design and automate delivery pipelines and cloud infrastructure on AWS, using Terraform, Docker, Kubernetes (EKS), Jenkins, GitHub Actions and Argo CD, and I'm extending that work into MLOps and AIOps.

- 🔬 **Working on** MLOps and AIOps projects, end to end
- 📚 **Learning** advanced Kubernetes and Terraform
- 🤝 **Open to** collaboration on cloud, CI/CD, ML pipeline and automation projects
